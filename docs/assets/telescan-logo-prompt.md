## Prompt

Use case: logo-brand
Asset type: open-source project's primary logo, for README and project branding.
Primary request: Create a polished, distinctive logo for "telescan", a lightweight command-line tool that scans local application configurations to reveal enabled telemetry and explain opt-outs.
Subject: A compact geometric scanning mark that subtly combines a lowercase t with a scan arc and a single detected signal dot, paired with the wordmark. Make the symbol feel purposeful, clear, and original; avoid piling up multiple metaphors.
Style/medium: Flat, vector-friendly graphic design, precise bold geometry, restrained typography, excellent small-size legibility.
Composition/framing: One horizontal logo lockup, icon to the left and lowercase wordmark to the right, centered with modest clear space. Large usable logo on a landscape canvas.
Text (verbatim): "telescan"
Typography: Confident clean lowercase sans serif with a subtle technical character and careful spacing.
Scene/backdrop: Genuinely transparent background with alpha.
Constraints: One finished logo only. Keep the design simple and reproducible in one color. No slogan, no extra text, no mockup, no presentation board, no shadows, no gradients, no 3D, no watermark. Avoid generic shields, locks, eyes, and Telegram paper planes. Choose a restrained ink color with good readability on a light README background.
