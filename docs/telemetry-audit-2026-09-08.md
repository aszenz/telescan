# Telemetry flag audit — 2026-09-08

All 71 catalog entries were searched individually. This audit favors vendor documentation and upstream source. “Confirmed” means the named control is supported, **not** that every accepted value, storage path, version, precedence rule, plugin, or running process has been verified. “Qualified” means the control has narrower scope or unresolved implementation details. “Mismatch” identifies a concrete conflict with the existing catalog. “Unresolved” means the research did not establish the claim; it does not mean telemetry is enabled.

This is a documentation/source audit, not a network capture or an execution test of all 71 products. Source links to moving branches describe what was available on the audit date. A scanner-shell environment variable does not establish the environment of an already running application or daemon. Missing preferences and configuration overrides must not be mistaken for confirmed effective consent.

The findings below describe the catalog at the start of this audit. Corrections applied during this audit are listed after the table; remaining limitations are deliberately retained here for follow-up.

## Corrections applied

- Removed `docker-cli-hints`: Docker's hints/hooks setting invokes local CLI
  plugin hooks and is not a telemetry control.
- Corrected the Gemini CLI setting to
  `privacy.usageStatisticsEnabled` and included its documented configuration
  layers.
- Marked Cordova telemetry as removed in CLI 13 and opt-in in older releases.
- Corrected Angular, Firebase CLI, and gcloud fresh-install defaults to opt-in.
- Corrected Astro's persistent key and cross-platform config locations.
- Added AWS CDK 2.1100.0+ CLI telemetry as a control independent from library
  version reporting.
- Corrected exact environment-value semantics for Flutter, RedwoodJS,
  Turborepo, and Vagrant.
- Removed the stale Flutter config check, npm's unsupported
  `NO_UPDATE_NOTIFIER` advice, and Go's unsubstantiated counter-deletion claim.
- Replaced unsupported Cursor and Edge local-state verdicts with manual review,
  and updated Edge to the current `DiagnosticData` managed policy.
- Qualified Snyk's opt-out as optional analytics only, added Composer repository
  notifications, and version-qualified Prisma 6 and 8 controls.
- Modeled Storybook's startup event and Syncthing crash reporting as controls
  independent from their regular telemetry settings.
